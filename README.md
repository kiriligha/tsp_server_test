# CacheServer 

## Описание работы команд
Сервер использует вариацию Redis-протокол
- **GET key**: Возвращает значение по ключу, если не expired, eсли нет — nil ($-1). Формат: *2\r\n$3\r\nGET\r\n$<len>\r\n<key>\r\n
- **SET key value [EX seconds]**: Устанавливает значение, если EX задан задаёт TTL в секундах. Формат: *3\r\n$3\r\nSET\r\n$<len>\r\n<key>\r\n$<len>\r\n<value>\r\n или *5\r\n$3\r\nSET\r\n$<len>\r\n<key>\r\n$<len>\r\n<value>$2\r\nEX\r\n$<len>\r\n<seconds>\r\n
- **DEL key**: Удаляет ключ из кэша, возвращает OK. Формат: *2\r\n$3\r\nDEL\r\n$<len>\r\n<key>r\n
  - TTL: Целое число секунд, очистка происходит каждую секунду.

## Инструкция по запуску
1. Установите Python 3.12+.
2. Запустите: `python server/server.py` (слушает 0.0.0.0:6379).
3. Для тестов: `pip install pytest`, затем `pytest tests/test_server.py`.
4. Docker: `docker build -t cache-server .`, затем `docker run -p 6379:6379 cache-server`.
5. Клиент: `python client/client.py` или(через redis-cli) `redis-cli -p 6379 SET key value`.

## Расширяемость
Чтобы добавить команду:
1. В `_process_command` добавьте в `handlers`: `'NEWCMD': self._handle_newcmd`.
2. Реализуйте метод `def _handle_new_command(self, command: list) -> bytes`.
3. Обработайте аргументы, используйте `self.cache`/`self.ttl`.
4. Добавьте тесты в `test_server.py`.

# Альтернативы
1. Рассматривал использование asyncio для лучшей производительности при большом количестве соединений, это позволило бы обрабатывать клиентов без потоков, но уменьшило бы читаемость кода, поэтому я решил остаться на потоках.
2. Рассматривал хранение данных в файле, но это медленнее, и это в этом нет необходимости, поэтому воспользовался обычных словарем, который прекрасно справляется с работой.
3. Можно было усложнить RESP парсер, но в этом также нет необходимости, я оставил только чтение массивов и строк, что достаточно для необходимых команд.
4. Расширяемость за счет классов(новая команда - новый класс), решил создать словарь из хендлеров, который легко реализуется и прекрасно справляется со своей задачи
