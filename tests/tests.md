# Тест-кейсы для CacheServer

### Риски
- Парсинг RESP: Неполные данные, неверный формат.
- Ошибки: Неверные команды, аргументы, TTL, пустые ключи/значения

### Тест-кейсы
1. **SET/GET**: Установить значение и получить его. Проверяет хранение.
2. **GET nothing**: Возвращает nil для отсутствующего ключа.
3. **SET with TTL**: Установить с EX, получить сразу, затем после истечения получить nil.
4. **Invalid command**: Неизвестная команда возвращает ошибку.
5. **Wrong args for SET**: Недостаточно аргументов.
6. **Wrong args for GET**: Недостаточно аргументов.
7. **Invalid TTL**: Неверное значение для EX.
